ABSTRACT

This report presents the technical design, development, and implementation work carried out during the eight-week Summer Internship, which commenced on 29 June 2026. The objective of the internship was to engineer a robust, production-grade Web-Based Expense Tracker and Financial Analytics Platform, designated SpendWise. The platform addresses the critical challenge of personal financial management by providing an intuitive, transparent, and data-driven web portal that enables individuals to log monetary expenditures, categorize financial streams, monitor multi-month budgets, inspect interactive analytical charts, and dynamically convert financial values across global currencies.

The system is engineered as an end-to-end full-stack application. The backend is developed using Node.js and Express.js (v4.21) resting upon an embedded SQLite3 relational database. The backend employs a modular MVC controller-service architecture, structured parameter validation, robust SQL aggregations, and RESTful routing exposing endpoints for transaction lifecycle management, financial summary computations, monthly trend aggregations, category breakdowns, and category budget enforcement. To deliver reliable multi-currency calculations without third-party rate limits, the backend integrates with an external open exchange rate API with a 1-hour in-memory cache and automatic fallback datasets.

The frontend is built using React 18 bundled with Vite, written in modern modular JavaScript and styled using Tailwind CSS. Data visualization is powered by Recharts, delivering responsive, interactive monthly income vs. expense comparison charts (switchable between Bar and Area modes) and category expense distribution Donut charts with custom tooltips. Key functional components include responsive KPI summary cards (Net Balance, Total Income, Total Expenses, and Savings Rate), a category-wise monthly budget tracker with automated color-coded alert badges (Safe, Warning, Exceeded), a live currency converter calculator widget, a multi-parameter transaction filtering engine, instant CSV export capabilities, and a 1-click realistic demo data seeder.

The report describes the project architecture and the activities of each of the eight weeks, explains each module in detail, discusses the challenges encountered and their solutions, and summarises the technical and professional skills gained. The internship provided a strong practical foundation in full-stack development and in the engineering of a complete, data-driven financial application.

1. INTRODUCTION

1.1 Background of the Internship

In modern technical education, hands-on industrial and project-based experience is essential to bridge academic theory with real-world software engineering practices. As part of the Bachelor of Technology in Information Technology curriculum under Anna University at Kingston Engineering College, the course IT3711 – Summer Internship serves as an intensive practical training ground. The internship took place over an eight-week duration during the academic period 2026–2027.

The internship assignment focused on conceptualizing, architecting, developing, testing, and deploying a complete, production-grade web application: SpendWise, a full-stack personal finance and expense analytics platform. The project provided thorough exposure to the end-to-end software development lifecycle (SDLC), including requirements gathering, relational database normalization, server-side REST API development, asynchronous client-side state management, interactive data visualization, and third-party API integration.

1.2 Objectives of the Project

The primary objectives established for the SpendWise platform comprise:

  • Accurate Transaction Logging: Enable users to seamlessly record and manage financial transactions with comprehensive metadata, including transaction amount, type (Income or Expense), category, date, payment method, and descriptive notes.
  • Visual Financial Analytics: Provide graphical intelligence on cash flows through multi-month trends and category spending distributions using interactive charting libraries.
  • Proactive Budget Monitoring: Implement category-specific monthly budget caps accompanied by visual indicators and automated threshold alerts (Safe, Warning, Exceeded) to prevent financial overspending.
  • Real-Time Currency Conversion: Integrate external live exchange rate services with an in-memory caching mechanism to enable seamless on-the-fly dashboard currency recalculation.
  • Data Portability: Enable instant export of historical transactions into industry-standard CSV format for spreadsheet auditing and personal record keeping.
  • Zero-Configuration Relational Persistence: Utilize an embedded, high-performance SQLite relational database to ensure self-contained portability without requiring manual database server configuration.

1.3 Problem Statement & Domain Context

Personal financial stability requires transparent visibility into daily spending patterns. Traditional expense tracking approaches—such as physical paper diaries, static spreadsheet templates, or complex commercial banking software—suffer from several significant limitations: high friction, lack of real-time intelligence, absence of currency versatility, and data clutter. SpendWise addresses these shortcomings by integrating logging, automated SQL analytics, interactive visualizations, and live currency rates into a unified single-page web application.

1.4 Scope of the Work

The project scope encompassed requirements gathering, relational database modeling, Node.js/Express.js backend development, React 18 client-side interface construction, Recharts data visualization, external currency API integration, automated demo seeding, and rigorous verification testing.

1.5 Organisation of the Report

The report follows the eight-week development progression. Chapter 2 describes the project architecture. Chapters 3 to 10 chronicle Weeks 1 to 8 respectively. Chapter 11 details module-wise functional specifications. Chapter 12 discusses challenges and solutions, Chapter 13 outlines skills acquired, and Chapter 14 concludes the report.

2. PROJECT OVERVIEW AND SYSTEM ARCHITECTURE

2.1 Project Overview

SpendWise is architected as an enterprise-patterned full-stack web application. It cleanly decouples the presentation tier (built in React 18 with Vite and Tailwind CSS) from the backend API services (powered by Node.js and Express.js) and data persistence tier (SQLite3).

2.2 System Architecture

The architecture adopts a 4-layer design:

  • Presentation Layer: React components providing responsive visual interfaces, custom charting, and global currency context.
  • Application Layer: Express.js handling routing, input validation, SQL query preparation, and metric calculations.
  • Integration Layer: External exchange rate API client with 1-hour in-memory cache and offline fallback dataset.
  • Persistence Layer: Relational SQLite3 database storing transactions, budgets, and categories.

3. WEEK 1 – REQUIREMENT ANALYSIS AND ENVIRONMENT SETUP

Week 1 (29 June 2026 – 5 July 2026) was dedicated to domain study, requirement specifications, and environment setup. Key personal finance workflows were modeled, architectural boundaries between client and server were established, and development tooling (Node.js, npm, Git) was configured on Windows x64.

4. WEEK 2 – DATABASE MODELLING AND REST API FOUNDATION

Week 2 (6 July 2026 – 12 July 2026) established the data foundation. In server/src/db/database.js, SQLite database initialization scripts were created. Asynchronous wrapper helpers (dbRun, dbGet, dbAll) were developed to enable clean async/await syntax. Initial REST endpoints for transactions and health checks were implemented and verified.

5. WEEK 3 – TRANSACTION ENGINE AND CSV EXPORT

Week 3 (13 July 2026 – 19 July 2026) expanded the transaction management controller. Dynamic parameterized SQL filtering was engineered to support real-time text searching across notes, category filters, transaction type toggles (expense/income), and date range limits. A dedicated CSV export endpoint (GET /api/export/csv) was implemented to stream formatted transaction spreadsheets directly to the user.

6. WEEK 4 – FINANCIAL ANALYTICS AND BUDGETING LOGIC

Week 4 (20 July 2026 – 26 July 2026) focused on financial analytics. SQL aggregation queries were developed in analyticsController.js to compute Net Balance, Savings Rate, and month-over-month percentage changes. Multi-month cash flow trends were grouped using SQLite's strftime('%Y-%m', date). Category budgeting logic was established to compute percentage consumption and classify statuses into Safe, Warning, and Exceeded.

7. WEEK 5 – REACT FRONTEND ARCHITECTURE AND KPI METRICS

Week 5 (27 July 2026 – 2 August 2026) initiated frontend construction. Vite and React 18 were configured with Tailwind CSS. A centralized Axios service (api.js) was created with internal development proxying. The SummaryCards.jsx component was developed to display four executive KPI cards with pulse loading states.

8. WEEK 6 – DATA VISUALIZATION AND BUDGET TRACKER UI

Week 6 (3 August 2026 – 9 August 2026) delivered visual analytics. Recharts was integrated in ChartsSection.jsx to render monthly cash flow trends (toggleable between Bar and Area views) and an interactive category distribution Donut chart. The BudgetProgress.jsx component was built with color-coded alert indicators and inline budget editing.

9. WEEK 7 – CURRENCY EXCHANGE API AND CONVERTER WIDGET

Week 7 (10 August 2026 – 16 August 2026) implemented multi-currency intelligence. The backend was connected to live exchange rate APIs with a 1-hour in-memory cache and offline fallback. A global CurrencyContext.jsx provider was built to dynamically recalculate all dashboard figures across eight world currencies. An interactive CurrencyConverter.jsx calculator widget was created.

10. WEEK 8 – INTEGRATION, SEEDING, TESTING AND REVIEW

Week 8 (17 August 2026 – 23 August 2026) finalized the platform. An automated realistic demo data seeder was created with 34 multi-month transactions. Full-stack integration was completed, and comprehensive end-to-end tests confirmed all endpoints and calculations. The frontend production build succeeded with zero errors (2,759 modules transformed).

11. MODULE-WISE FUNCTIONAL DESCRIPTION

SpendWise is composed of five core modules:

  • Transaction Lifecycle Management: Add, edit, delete, search, and filter expenses and income streams with full input validation.
  • Financial Visual Analytics: Real-time KPI summaries, interactive Recharts cash flow trends, and category expense distribution Donut charts.
  • Category Budgeting & Alerts: Category spending boundaries with visual progress indicators and threshold alert badges.
  • Global Currency Intelligence: Real-time exchange rate fetching, 1-hour server caching, dashboard recalculation, and conversion calculator.
  • Data Portability & Utilities: 1-click CSV export and sample data generator.

12. CHALLENGES FACED AND SOLUTIONS ADOPTED

Key engineering challenges encountered during the internship included:

  • CORS & Dev Proxying: Resolved via Vite's internal proxying configuration.
  • Currency API Latency: Mitigated using an in-memory caching layer with a 1-hour TTL and hardcoded offline fallback rates.
  • Multi-Currency Normalization: Stored all monetary figures in base USD in the database and applied dynamic client-side conversions for display.
  • Responsive Charting: Implemented responsive Recharts containers ensuring seamless layout adaptation across desktop and mobile viewports.
